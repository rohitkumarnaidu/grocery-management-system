# Security Policy

Use this section to tell people about which versions of your project are
currently being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please report any security vulnerabilities by opening an issue on this repository or contacting the maintainer directly. 
When reporting a vulnerability, please include:
- A detailed description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact and affected versions.

We take all security vulnerabilities seriously and will address them as quickly as possible.
